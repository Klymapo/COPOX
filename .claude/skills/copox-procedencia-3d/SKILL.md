# COPOX · Procedencia y licencias de activos 3D

1. Leer `docs/COPOX_PROCEDENCIA_HUNYUAN_2026-10-14.md` y `docs/MANIQUI_HIBRIDO_2026-10-14.md`.
2. Extraer fuente de cada componente: malla, textura, materiales, rig, animaciones, referencias de concepto y cada GLB usado como base. Documentar SHA/URL/fecha de generación y versión de servicio/licencia si se conoce.
3. Clasificar `VERIFICADO_PROPIO`, `TERCERO_CONDICIONES`, `SIN_VERIFICAR` o `ORIGEN_MIXTO`. Nunca deducir independencia por % de cambio, distancia entre siluetas o regeneración algorítmica.
4. Señalar la ruta Beta + Gamma Hunyuan -> Delta -> Maniquí -> r3; tratar los activos históricos como origen mixto hasta comprobar derechos y cumplimiento.
5. Para nueva familia independiente, diseñar desde referencias propias o CC0 comprobadas y una baseline sin importar/interpolar/trasplantar vértices, texturas ni formas trazadas desde Gamma. El algoritmo matemático puede ser propio; cada malla resultado debe tener trazabilidad independiente.
6. Distinguir licencia del **modelo de IA**, condiciones de **outputs** y **TOS del servicio**. Verificar versión y fecha exacta. No atribuir a outputs automáticamente todas las condiciones de derivados de pesos.
7. No borrar ni alterar originales sin consultar; no anunciar certificación legal. Registrar recomendación para asesoría profesional si habrá lanzamiento comercial/internacional.
8. La revisión NO desbloquea la promoción técnica; exige por separado QA artístico y Godot.
