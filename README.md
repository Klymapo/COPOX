# COPOX · capturas

Rama solo de capturas del renderizador (`copox/render`, rama de código `propuesta/motor-medicion-v2`). No lleva código ni GLB.

- Ruta: `capturas/AAAA-MM-DD/<modelo>/<autor>/<vista>_<modo>_<tam>.png` (autor: `elio` o `argos`).
- Cada imagen lleva un sello con modelo, hash, vista, modo, autor, fecha y el **código de vista** para repetir la toma.
- Al cerrar cada etapa: las capturas se empaquetan en un zip como Release (`capturas-etapa-NN`) y la rama se reinicia conservando solo las láminas finales, con aprobación de Admin.
