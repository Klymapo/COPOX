## Convención

A partir de esta rama, cuando la documentación diga **Theo Alpha** se refiere al modelo derivado de `theo_v11_rehecha.glb`; **Alastor Alpha** o **Detective Alpha** se refiere a `detective_v3_likeness_t_pose.glb`.

Estas versiones son una línea base visual, no modelos finales. Las siguientes iteraciones deben versionarse como Beta o como nuevas revisiones Alpha explícitas, sin sobrescribir esta referencia.
